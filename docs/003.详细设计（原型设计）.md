# 智能家庭饮食管家 App - 详细设计文档

## 0. 设计约定与单位标准

**重要变更（v1.1）**：根据数据库设计文档 v1.4/v1.8 的决定，本项目统一采用 **g（克）** 或 **ml（毫升）** 作为食材计量单位。

**单位标准**：
- 所有食材的 `unit` 字段仅允许填写 **g** 或 **ml**
- 菜谱用量、库存数量、采购量均以 **g/ml** 为基准直接计算
- **已删除** `default_weight_per_unit` 换算字段，不再支持"个/枚/颗"等非标准单位
- 菜谱录入时，用户需直接填写 g/ml 单位的数量（如"300"而非"2个"）

**历史数据兼容性**：对于已录入的包含非 g/ml 单位的历史数据，需在迁移脚本中转换为标准单位。

---

## 1. 全局交互与基础规范

- **色彩体系**：主色暖柔青柠绿（#64C288）、辅助色活力橙（#FF9A5A）、预警色豆沙红（#E86B6B）。
- **动效规范**：页面切换采用轻微左滑进入；按钮点击具备下沉缩放反馈；半屏抽屉弹出时长控制在 0.3s。
- **数据同步机制**：采用 WebSocket 长连接技术。任意成员的库存修改、菜单变动需在 **2秒内** 推送至所有在线家庭成员设备，确保并发一致性。

## 2. 注册与引导模块

### 界面一：Step 1 个人档案建立

- **页面目标**：收集用户基础身份与健康数据，计算 TDEE（每日能量消耗），为个性化膳食推荐提供算法支撑。
- **顶部导航区**：显示进度"1/2"，配文"先让我们了解你"。
- **核心表单区（垂直居中布局）**：
    - **昵称录入**：大尺寸圆角矩形输入框（16px圆角，背景纯白 #FFFFFF，边框浅灰 #E5E7EB）。左侧内嵌浅灰色"人物"线性图标，占位符提示"请输入您的昵称"。
    - **身体数据组**：身高、体重、年龄三项采用**三列并排**布局。每个单元格为白色圆角卡片，上方展示浅灰标签（如"身高/cm"），下方为大字号深灰（#333333）数字输入区。
    - **性别选择**：提供"男生"与"女生"两个并排的圆角卡片按钮。默认状态边框为浅灰；选中态边框与图标变为暖柔青柠绿（#64C288），背景叠加主色10%透明度。
    - **饮食目标单选**：纵向排列的卡片式选项，包含"健康减脂"、"增肌塑形"、"日常维持"。选中时卡片边框高亮为主色，并附带主色小对勾图标。
- **底部操作区**：通栏实心按钮，文案"下一步"，背景色暖柔青柠绿，文字纯白。点击校验通过后跳转至 Step 2。

### 界面二：Step 2 家庭关系绑定

- **页面目标**：确立用户的协作归属，完成从个人工具到家庭共享平台的身份切换。
- **顶部导航区**：显示进度"2/2"，配文"创建或加入你的家庭小组"。
- **核心内容区**：
    - **创建新家庭（主流程）**：大尺寸实心主色按钮（背景 #64C288，文字纯白，16px圆角）。点击后系统自动生成家庭ID，用户作为 Owner 直接进入 App 首页。
    - **加入已有家庭（次流程）**：大尺寸描边样式按钮（边框 #64C288，背景透明，文字 #64C288，16px圆角）。点击后触发底部半屏抽屉。
    - **邀请码输入抽屉**：从底部平滑上滑弹出（12px顶部圆角，背景纯白）。内部包含一个支持6位字符的大号字间距输入框，自动唤起数字键盘。输入完成后自动校验，成功则关闭抽屉并进入首页。
- **异常处理**：若在 Step 2 输入了无效或已过期的邀请码，需在输入框下方以豆沙红（#E86B6B）文字提示"邀请码无效，请核对后重试"。
- **底部辅助说明**：居中展示一行浅灰色小字（#999999）："您可以随时在个人中心邀请家人加入。"

### 逻辑规则补充

- **数据联动**：在 Step 1 填写完身高、体重、年龄、性别后，后台需实时调用 Mifflin-St Jeor 公式预计算用户的 BMR 与 TDEE，供首页后续推荐算法直接调用。

## 3. 首页 - 今日膳食控制台

### 顶部动态控制区

- **当前掌勺人展示（左侧）**：展示当前组长的圆形头像与昵称（例如："今天由 爸爸 掌勺"）。点击该区域可唤起底部的成员列表抽屉，支持快速切换当天的掌勺人。切换后，系统推荐算法会适当向新任组长的口味偏好倾斜。
- **用餐人数步进器（右侧）**：采用胶囊形控件，包含"-"、"数字"、"+"三个部分。默认读取个人中心预设的家庭常驻人数，支持用户根据当天实际情况临时增减。修改人数后，下方的营养目标与菜谱份量需实时联动刷新。

### 核心数据可视化区（左文右图）

- **左侧：营养素含量详情与对比（双柱状图，约占40%宽度）**
    - **布局形态**：横轴分别为三大营养素（碳水、蛋白质、脂肪），纵轴代表含量（克）。采用三组并列的竖向柱子进行同类数据对比。
    - **实心柱（暖柔青柠绿 #64C288）**：代表"当前菜谱累计摄入量"。作为前景主视觉，柱体顶端直接标注具体的克数（如 85g），字体使用深灰（#333333）加粗。
    - **描边空心柱（浅灰占位 #999999）**：代表"个人每日推荐摄入量"。采用 2px 的线性描边风格，内部透明，作为背景参照物高度固定。
    - **交互联动**：当用户在下方切换"饮食模式标签"时，后方的描边空心柱（推荐量）会平滑地上下伸缩，直观展示出目标的改变。
- **右侧：营养占比仪表盘（环形图，约占60%宽度，整体偏右对齐）**
    - **形态与配色**：采用 3/4 环形仪表盘，底部留白处居中展示今日总热量数值（深灰 #333333，特大号加粗字体）。扇区严格按照碳水（暖杏黄 #F9D07B）、蛋白质（浅湖蓝 #72B5E4）、脂肪（暖柔青柠绿 #64C288）进行填充，扇区间保留纯白微小间隙。
    - **入场动效**：页面加载或数据变动时，环形色块从 0 度开始顺时针动态旋转向外生长，带有轻微回弹效果，耗时 0.9秒；同时中心热量数字从 0 滚动累加至实际值。

### 饮食模式切换标签

- **位置与形态**：位于仪表盘正下方，采用横向滑动的胶囊标签组（8px小圆角）。
- **样式逻辑**：采用"低透明度背景 + 同色文字"的轻量样式。减脂（背景 #64C288 (20%)，文字 #64C288）、增肌（背景 #FF9A5A (20%)，文字 #FF9A5A）、正常维持（背景 #999999 (20%)，文字 #999999）、聚餐（背景 #72B5E4 (20%)，文字 #72B5E4）、放纵餐（背景 #F9D07B (20%)，文字 #F9D07B）。
- **交互**：点击不同标签，左侧图表的描边空心柱（推荐量）即时平滑过渡到对应阈值（如放纵餐=120% TDEE）。

### 三餐推荐卡片流与心愿单

- **纵向分区**：按早餐、午餐、晚餐从上至下排列。每个餐别标题左侧带有对应颜色的微型色块标识。
- **家人想吃（心愿单）**：在常规推荐上方，增加"家人想吃"横向滑动卡片区。普通成员推荐的菜品带"心愿"标签，掌勺人可一键采纳进今日菜单。
- **横向滑动卡片**：每个餐别下方包含一组可横向滑动的菜谱卡片。卡片采用纯白背景，16px大圆角。若某道菜被用户主动锁定，卡片右上角叠加豆沙红的小锁图标。每张卡片的右上角均有一个微小的"刷新"线性图标，点击仅替换当前这一张卡片的内容。

### 悬浮操作与底部导航

- **悬浮操作按钮（FAB）**：右下角固定悬浮一个圆形主色按钮（#64C288），内嵌白色"购物袋"图标。点击直接进入"智能采购清单"预览页。
- **底部导航栏（Tab Bar）**：保持全局统一的四大入口（首页、食谱库、共享冰箱、我的），当前页面"首页"图标与文字呈暖柔青柠绿高亮态。

## 4. 食谱库与详情页

### 顶部双Tab切换区

- **布局形态**：页面最上方固定悬浮两个大尺寸Tab选项："找菜谱"与"查食材"。下方带有暖柔青柠绿的滑动下划线指示器。
- **交互逻辑**：左右滑动页面主体内容时，顶部的Tab会自动跟随切换；点击Tab则平滑滚动到对应的内容板块。

### 智能胶囊标签筛选区

- **布局与形态**：在顶部搜索框正下方，预留约两行高度的空间。内部采用横向滚动的流式布局。
- **选中与固定逻辑**：点击任意一个待选标签，背景色瞬间切换为主色样式，并自动吸附到最前方。支持多选（最多4-5个），再次点击已选中标签则取消并释放回后方区域。

### "找菜谱"与"查食材"板块

- **全局搜索框**：位于筛选区上方，大圆角白色输入框，左侧带有线性放大镜图标。
- **找菜谱内容区**：经典的双列不等高瀑布流布局。卡片展示高清封面图、菜名、核心营养标签（活力橙突出热量）及烹饪时长。
- **查食材内容区**：单列纵向列表展示常见食材。每行左侧为极简插画，中间为名称及热量，右侧为向右箭头。未输入时展示"最近搜索"历史标签。

### 全局悬浮新增按钮（FAB）

- **交互逻辑**：点击右下角圆形主色"+"号按钮，从底部平滑弹出半屏抽屉，提供"新建菜谱"和"新建食材"两个选项。

### 自定义新增功能模块

- **"新建菜谱"表单页**：支持上传封面图；输入名称、时长、几人份；录入营养数据（支持智能估算）；动态添加食材清单与烹饪步骤；打标签管理。
- **"新建食材"表单页**：输入名称、单位；录入每100g营养成分。**新增OCR功能**：顶部增加"拍包装识别营养"入口，调用摄像头扫描食品包装袋营养成分表，利用OCR技术自动填入数据。

### 菜谱详情页设计方案

- **顶部沉浸式视觉区**：铺满高清成品大图，底部带黑色渐变蒙层。左上角"返回"，右上角"收藏"（点击填充豆沙红）。蒙层上展示菜名、总热量（活力橙高亮）、烹饪时长。
- **悬浮式二级导航栏**：紧贴首图下方，包含"概览"、"食材"、"步骤"、"营养"四个Tab，随滑动吸顶并自动切换。
- **概览板块**：简介文本与口味标签。核心交互为通栏大按钮"加入今日午餐/晚餐"（描边样式，点击变实心并提示）。
- **食材清单板块**：标题右侧放置份量步进器（- 2人份 +），调整份数后用量自动换算。列表项支持点击小圆圈标记"已备齐"。
- **烹饪步骤板块**：纵向时间轴布局，带序号、文字说明及可选步骤图。
- **营养深度拆解板块**：复用首页的"3/4环形仪表盘"和"双柱状图"，展示该菜品本身的营养构成。
- **底部固定操作栏**：左侧"分享给家人"；右侧主按钮根据状态动态变化（未加入显示"加入今日膳食"，已加入显示"查看采购清单"或"开始烹饪"）。

## 5. 家庭共享冰箱

### 顶部状态与智能预警区

- **当前冰箱标识**：页面最上方居中展示当前家庭名称，支持点击唤起抽屉切换家庭。
- **动态智能横幅**：
    - **灵感推荐态**：默认展示暖杏黄背景卡片，根据临期食材生成灵感（如"西红柿快熟透啦，做个番茄炒蛋吧！"）。
    - **过期强提醒态**：检测到过期食材时，自动替换为强提醒文案，点击可筛选出所有过期物品。

### 分类标签与库存网格

- **分类标签导航栏**：横向滚动的胶囊形标签（全部、果蔬生鲜、肉蛋水产等）。选中态背景变为主色（20%透明度），文字变为主色。
- **食材库存网格区**：双列或三列网格瀑布流。卡片右上角状态标识：新鲜（绿点）、余量不足（橙点）、即将过期<3天（橙点+文字高亮）、已过期（红色蒙层+感叹号）。长按卡片弹出快捷菜单（加购/吃完/编辑）。

### 底部悬浮操作与权限控制

- **添加食材按钮（FAB）**：右下角固定悬浮圆形主色按钮，点击弹出半屏抽屉（扫码/AI拍照/手动输入）。
- **入库权限拦截机制**：系统实时校验角色。无权限成员点击 FAB 时，立即拦截并弹出 Toast："您暂无入库权限，请联系掌勺人或户主开通"。
- **同步家人更新**：FAB 左侧悬浮长条形白色胶囊按钮。远程数据变动时出现红色数字角标（如"+1"），点击拉取最新状态。

### 智能采购清单核心逻辑

- **自动生成算法**：`实际需采购量 = 菜谱所需总量 - 冰箱现有量`。若结果 <= 0（库存充足），该项自动过滤，绝不进入采购清单。
- **批量入库闭环**：在采购清单页勾选"已购买"后，点击"一键入库"，直接将数量累加至共享冰箱库存。

## 6. 烹饪完成与库存智能核销

### 触发机制与权限校验

- **触发入口**：在首页三餐卡片或菜谱详情页，用户点击"开始烹饪"并进入尾声时，主按钮变为"标记制作完成"。
- **权限强校验**：核销权限归属于**掌勺人**或**户主**。若普通成员（非掌勺人且非户主）点击该按钮，立即拦截并弹出 Toast："仅掌勺人或户主有权确认菜单完成及核销库存"。

### 库存核销弹窗（核心交互界面）

- **弹窗形态**：屏幕中央弹出半屏抽屉或大尺寸模态框，标题为"本次烹饪将消耗以下食材"。
- **食材列表布局**：弹窗主体为可纵向滚动的食材清单，每个食材独占一个独立卡片区域：
    - **第一行（信息展示）**：左侧展示食材名称（深灰加粗）；右侧展示当前冰箱实时库存量（次级文字色，如"现有 500g"）。
    - **第二行（核销操作区）**：
        - **可视化进度条**：位于操作区底层。底色浅灰，填充色为主色。长度动态代表"本次消耗量占当前总库存的百分比"。当消耗量接近或等于库存时，进度条自动变为活力橙预警。
        - **数字输入框**：悬浮在进度条左侧，默认预填菜谱所需的标准用量，支持手动修改。修改后进度条与右侧库存余量实时联动。
        - **清空按钮**：位于进度条右侧，采用豆沙红文字或图标。点击后直接将本次核销量设为当前全部库存（一键将该食材从冰箱移除）。
- **底部操作栏**：弹窗最底部固定两个按钮。左侧为灰色描边的"取消"，右侧为实心主色的"确认核销"。

### 后台数据联动逻辑

- **执行扣减**：掌勺人或户主点击"确认核销"后，后台立即执行公式：`冰箱最新库存 = 原库存 - 本次核销量`。
- **跨端同步**：核销结果遵循"2秒同步承诺"，通过 WebSocket 推送至所有家庭成员设备。

## 7. 个人中心与家庭管理

### 个人专属信息区

- **头部个人信息卡片**：展示头像、昵称及家庭角色标签。背景采用极淡的主色渐变。
- **我的营养档案**：快捷入口进入"营养目标设置"，可修改基础代谢率、热量缺口及过敏源食材。

### 家庭协作与管理核心

- **当前掌勺人与移交权杖**：
    - **位置与展示**：家庭管理板块首项。左侧显示现任掌勺人信息，右侧放置"移交掌勺权"按钮（仅掌勺人可见）。
    - **移交流转交互**：点击唤起底部半屏成员选择抽屉 -> 选中目标 -> 弹出高优先级模态弹窗二次确认 -> 后台更新数据，全员2秒内同步刷新。
- **家庭成员列表与权限分配**：
    - **成员展示**：纵向卡片列表，右侧显示身份状态。
    - **权限开关**：家庭创建者可在其他成员旁看到"权限开关"，用于授予/收回"冰箱入库权限"和"菜单最终确认权"。
- **邀请与退出机制**：底部提供"邀请家人加入"按钮及红色的"解散/退出家庭"危险操作区。

### 个性化偏好与统计报告

- **口味雷达图**：五维雷达图展示口味偏好（咸甜酸辣鲜），支持拖动调整。
- **不爱吃的食材（黑名单）**：标签输入框，添加后在所有推荐场景强制降权或剔除。
- **家庭饮食统计与周期报告**：
    - **入口**：在"数据与缓存管理"板块下，新增"家庭饮食周报/月报"。
    - **可视化看板**：支持"个人视角"（热量趋势、达标率）与"家庭视角"（家庭总消耗、最爱菜品Top5、健康评分对比）切换。
    - **导出与打印**：支持将统计图表生成为长图或PDF，方便打印复盘。
    - **身体数据追踪**：支持自定义提醒周期（如每两周），通过本地通知提醒用户更新体重等数据。

### 通用功能与离线模式

- **离线模式与单机运行**：
    - **触发机制**：无网络环境或用户在设置中主动开启"离线模式"时，自动切换至本地运行。
    - **本地数据库支撑**：设备本地预置精简版"基础食材营养库"和"常用菜谱库"。无网状态下支持查看缓存菜单、记录饮食、录入新数据（暂存本地SQLite）。
    - **断点续传**：网络恢复后静默合并本地与云端数据，冲突时以云端最新时间戳为准。
