#### 三、估算系数说明（重要）

**⚠️ 单人开发的典型陷阱：** 纯编码时间估算忽略了调试、环境搭建、第三方库集成、UI调优和不可预见的Bug。

**本项目采用的现实估算系数：**

| 复杂度类型 | 原始估算 × 系数 | 说明 |
|-----------|:---------------:|------|
| 简单 CRUD + UI | × 1.5 | 表单页面、列表展示 |
| 中等逻辑 | × 2.0 | 业务计算、权限校验 |
| 复杂集成 | × 2.5 | WebSocket、数据库事务 |
