### 架构建议（记录）
| 当前 | 建议 |
|------|------|
| Repository 直调 DatabaseManager::instance().database() | 统一注入 QSqlDatabase，方便将来切换 PostgreSQL |
| 种子数据硬编码在 Service 构造函数 | 移到独立 Seeder 类或 JSON 文件 |
| Model 全程 QVariantList 传 QML | 考虑 QAbstractListModel 子类化，避免每次全量刷新 UI |
| 无测试覆盖 | 10 个 Service/50+ 方法 → 需 C++ 单元测试 + QML 组件测试 |
| 输入校验缺失 | QML TextInput 直传 C++，无范围检查 |
| 数据库迁移策略弱 | 只有 CREATE TABLE IF NOT EXISTS，加字段不会自动补 |
