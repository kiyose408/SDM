# 302. 成员管理：列表/权限/移交/移除 + 邀请码可见

**日期：** 2026-05-20
**关联开发任务：** 阶段 3 任务 3.2 成员管理
**关联设计文档：** 004.数据库设计文档 §4.3、009.开发规范文档

---

## 一、问题/需求

家庭成员管理需要：查看成员列表、户主可移交/移除成员、展示邀请码供分享。必须保证权限逻辑正确——仅户主可见操作按钮和邀请码，移交后旧户主降为成员。

---

## 二、思路

1. **Service 层集中权限**：`transferOwnership` 先验证操作者是户主，再交换角色
2. **邀请码仅户主可见**：`isOwner` 属性遍历成员列表检查当前用户角色
3. **双模式复用**：`FamilySetupPage` 加 `registrationMode` 属性——注册模式显示"上一步"和"2/2"，独立模式显示"返回"
4. **移除后家庭归零**：ProfilePage 底部提供"+ 创建或加入新家庭"入口

---

## 三、实施方案

### 新增 API

| 方法 | 功能 |
|------|------|
| `getMembers(familyId)` | 返回家庭所有成员 |
| `getUserFamilies(userId)` | 用户所属家庭列表（含邀请码）|
| `setMemberPermissions(...)` | 修改成员权限（库存/菜单确认）|
| `removeMember(familyId, userId, operatorId)` | 户主移除成员 |
| `transferOwnership(...)` | 户主交接（双向角色更新）|

### 文件变更

```
MemberListPage.qml    ← 新建：成员列表 + 移交/移除按钮 + 邀请码
ProfilePage.qml       ← 重写：家庭列表 + 创建加入入口
FamilySetupPage.qml   ← 改：双模式（registrationMode）
main.qml              ← 暴露 navStack 别名
```

---

## 四、踩坑

| 现象 | 根因 | 修复 |
|------|------|------|
| 移交按钮点击无反应 | `Dialog.open()` 未调用，仅设属性 | 加 `transferDialog.open()` |
| 邀请码始终为空 | `getUserFamilies` 未返回 `inviteCode` | 加字段 |
| 独立使用时点返回卡死 | FamilySetupPage 固定走 `backToStep1()` | 加 `registrationMode` 分支 |
| 登录后直接退出 | LoginWindow 被删前版本残留 `onClosing: Qt.quit()` | 移除 |
