# 403. 菜谱搜索 + 收藏功能

**日期：** 2026-05-22
**关联开发任务：** 阶段 4 任务 4.3
**关联设计文档：** 003.详细设计文档 §4、005.接口设计文档

---

## 一、问题/需求描述

用户需要在 40 道菜谱中快速找到想要的，并能收藏常用菜谱方便下次查看。

---

## 二、思路

**搜索**：简单 client-side 过滤，无需建索引或 SQL LIKE
- `RecipeService::searchByName(keyword)` → 遍历 getAll() 返回 name.contains(keyword)
- QML 侧 TextInput onChange → 实时调用 refresh

**收藏**：`recipe_favorites` 表
- `RecipeFavoriteRepository`：单表 CRUD
- 详情页心形按钮 toggle

---

## 三、逻辑推导

**搜索为什么不过数据库？**
- 40 道菜谱，全量遍历 O(40) ~= 0ms，加上 SQL 查询反而有开销
- 未来数据量增长到 500+ 时可以改用 LIKE %keyword%

**收藏 vs 标签的区别**
- 标签：给菜谱分类（红烧/辣/快手…），属于菜谱本身的元数据
- 收藏：用户个人行为，与菜谱无关，属于用户→菜谱的多对多关系

---

## 四、项目应用

- `RecipeListPage`：搜索栏 `TextInput.onChange → refresh(keyword)` → `searchByName` → 列表更新
- `RecipeDetailPage`：心形图标，加载时从 `recipeService.isFavorited(userId, recipeId)` 读状态
- 收藏图标：♥ 红色实心 / ♡ 灰色空心

---

## 五、验证

- 搜索"蛋" → 列表过滤为含"蛋"的菜谱
- 收藏一道菜 → 回到列表 → 收藏状态保持
- 切换用户 → 收藏列表不同
