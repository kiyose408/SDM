## 📊 项目概览

本项目基于 **Qt/QML** 框架开发，旨在构建一款集个性化膳食推荐、家庭共享冰箱管理、智能采购与烹饪核销于一体的 App。

- **项目类型**：跨平台桌面应用 (支持 Windows/macOS/Linux)
- **开发人员**：1人 (单人开发模式)
- **核心目标**：
  - 实现家庭饮食数据的多端实时同步 (承诺 < 2秒)。
  - 通过算法减少食材浪费 (智能采购清单)。
  - 提供科学的营养摄入管理 (TDEE/BMR 计算)。

### 🎨 设计语言
- **主色调**：暖柔青柠绿 (`#64C288`) —— 代表健康与活力。
- **辅助色**：活力橙 (`#FF9A5A`)、豆沙红 (`#E86B6B`)、暖杏黄 (`#F9D07B`)。

## 🛠️ 技术架构

本项目采用分层架构设计，确保高内聚、低耦合。

### 1. 技术栈
| 层级 | 技术/语言 | 说明 |
| :--- | :--- | :--- |
| **UI 层** | QML + JavaScript | 负责界面渲染与交互动效 |
| **业务层** | C++17 | 核心算法 (TDEE、采购清单生成、FIFO核销) |
| **数据层** | SQLite / PostgreSQL | 本地离线缓存 + 云端中央存储 |
| **通信层** | WebSocket (WSS) | 实时数据同步与推送 |

### 2. 核心算法逻辑
- **TDEE/BMR 计算**：采用 Mifflin-St Jeor 公式，根据用户档案实时计算。
- **智能采购清单**：`实际需采购量 = 菜谱所需总量 - 冰箱现有量` (自动过滤 <=0 的项)。
- **库存核销 (FIFO)**：先进先出策略，优先消耗临期食材批次。
- **数据同步**：基于时间戳的冲突解决机制，离线模式自动降级与断点续传。

## 🌟 核心功能模块

### 1. 冷启动与引导
- **个人档案**：收集身高体重年龄，实时计算 BMR/TDEE。
- **家庭绑定**：支持创建家庭与 6 位邀请码加入，确立家庭关系。

### 2. 首页：今日膳食控制台
- **数据可视化**：双柱状图（对比摄入与推荐）、环形仪表盘（展示碳水/蛋白/脂肪占比）。
- **饮食模式**：支持减脂、增肌、维持、聚餐、放纵餐等模式切换。

### 3. 家庭共享冰箱 (核心协作)
- **智能预警**：临期食材灵感推荐，过期强提醒。
- **库存管理**：多批次管理，状态可视化（新鲜/临期/过期）。
- **权限控制**：支持“掌勺人”与“户主”权限分级。

### 4. 烹饪完成与核销
- **权限校验**：仅**掌勺人**或**户主**可触发核销。
- **核销流程**：确认消耗食材 -> 扣减库存 -> 生成消费记录 -> 全员同步。

### 5. 离线模式
- 无网络时自动加载本地 SQLite 数据，支持全功能操作，网络恢复后静默同步。
